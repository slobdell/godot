# Voice clips (the recorded announcer)

2,396 Ogg Vorbis clips, 66 MB. Generated by `make announcer-generate APPROVED=1` from `../lines.json`; the masters
they were cut from are git-ignored (about 1.1 GB) and let anything here be re-cut without spending credits.

**One clip is one whole sentence.** A line with slots is recorded once per combination of values it can take, so
`caller.kill.01@law.tank` is "The Law take out the tank!" recorded as a single utterance. Nothing is assembled at
playback. Until round 4 clips were carrier fragments joined with recorded filler words at runtime; it sounded
pasted, because a sentence's intonation spans the whole sentence, and no amount of tuning the cuts fixed it
(`_agents/streams/archive/round4/audio.md`, *Why stitching failed*).

**Godot deliberately ignores this folder** (`.gdignore`, written by the generator so wiping the folder cannot lose
it). Nothing here is a Godot resource:

- `AnnouncerVoice` loads clips with `AudioStreamOggVorbis.load_from_file()` at runtime, by path.
- Importing them crashed the import step once, and is slow every time.
- They are excluded from both export presets. A core pack ships with the game and bigger voice packs arrive
  afterwards (game_design.md *The pipeline*); `--announcer-clips=DIR` points the booth at wherever the pack lives.

`manifest.json` **is** read, as a plain file, and is the only thing the game needs to know what is here.

## Clip ids

| Form | Example | What |
|---|---|---|
| `<line id>` | `pa.welcome.03` | a line with no slots |
| `<line id>@<values>` | `caller.kill.01@law.tank` | one realization; the values are in sorted base-slot order |

The key must match `AnnouncerLibrary.variant_key` and `recording_plan.variant_key` exactly, or the game asks for
clips that were never recorded. A test pins it on both sides.

## Verifying

`make announcer-generate` speech-to-text checks every clip as it is cut. Since every clip is now a complete
utterance the check is trustworthy, which it was not when clips were fragments. Flags are worth reading as a set
rather than one at a time: one is usually the recogniser, but **all eight variants of one line failing identically**
is a cause — that is how "a possessive followed by *own* elides at the caller's pace" was found.
